# shop-orders

Учебный проект для интеграционного тестирования: заказы товаров.
Слои: контроллер -> сервис -> репозиторий (Spring Data JPA) -> база данных (H2).

Сценарии: создать заказ (проверка остатка на складе, расчёт суммы), получить заказ, отменить заказ (возврат товара на склад).

Запуск тестов:

    mvn test

Тесты (19 штук) лежат в src/test/java/com/example/shop:

- topdown - нисходящие (контроллер + сервис, репозитории заменены заглушками)
- bottomup - восходящие (репозиторий и БД, затем сервис + репозиторий)
- converged - сходящиеся (все слои вместе)

Каждый push запускает GitHub Actions (.github/workflows/ci.yml).
